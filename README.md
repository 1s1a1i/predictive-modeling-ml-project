# Predictive Modeling Using Machine Learning

This project predicts student pass/fail outcomes using machine learning classification algorithms.

## Algorithms Used
- Decision Tree
- Random Forest

## Evaluation Metrics
- Accuracy Score
- Confusion Matrix
- ROC Curve

## Tools
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Outcome
Built and evaluated a supervised machine learning model for classification.
